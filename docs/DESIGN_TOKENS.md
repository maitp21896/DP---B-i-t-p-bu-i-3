# Tomorrow Marketers interface palette

These provisional reference colors come from the training slides and are not verified official brand hex codes. The shared CSS tokens live in `app/globals.css` and apply to every exercise screen, the trainer view, and the printed PDF report.

| Token | Value |
| --- | --- |
| Primary | #E91E83 |
| Dark pink | #C21870 |
| Purple accent | #A600D4 |
| Primary text | #171717 |
| Secondary text | #52525B |
| Page background | #F7F7F9 |
| Cards | #FFFFFF |
| Border | #E4E4E7 |

Magenta marks primary actions, selected navigation, progress, and sliders. Dark pink is used for small accent text; white labels on magenta primary buttons use 19px bold text for contrast. Purple marks focus outlines and a chart series. Pale pink surfaces are derived supporting tokens. Charts and budget bars share the same CSS color variables; their third series uses amber for distinction.

Tomorrow Marketers is the application brand. Glow Nature identifies the exercise case. Green is confined to the successful-submission confirmation, using semantic success tokens. Print uses the same color tokens with exact color adjustment, while preserving the compact A4 layout.
